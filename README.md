# REVIA AI

Application éducative.

## TESTER REVIA AI SUR ANDROID

Vous pouvez obtenir une version de test de l'application via les GitHub Actions :

1. Ouvrez l'onglet **Actions** dans ce dépôt GitHub.
2. Choisissez le workflow **Build Debug APK** dans la liste à gauche.
3. Si le workflow n'a pas été lancé, cliquez sur **Run workflow** (pour la branche `main`).
4. Attendez la fin de l'exécution.
5. Ouvrez le résultat du workflow terminé.
6. Téléchargez l'Artifact **REVIA-AI-debug-apk**.
7. Extrayez le fichier ZIP téléchargé.
8. Récupérez le fichier `app-debug.apk`.
9. Transférez l'APK sur votre téléphone Android.
10. Ouvrez le fichier APK sur votre téléphone et installez l'application (autorisez l'installation depuis une source inconnue si Android le demande).
